1 · Reihenfolge, Klammern, Begriffe

  • Potenz vor Punkt vor Strich, gleiche Stufe von links nach rechts, innerste Klammer zuerst.
  • Potenz kommt vor dem Minus: −2² = −4, (−2)² = 4, (−2)³ = −8.
  • Summand + Summand = Summe · Minuend − Subtrahend = Differenz · Faktor · Faktor = Produkt · Dividend : Divisor = Quotient · BasisExponent = Potenz · n√Radikand = Wurzel.
  • Kommutativ (tauschen), assoziativ (Klammern verschieben), distributiv (ausmultiplizieren/herausheben) – nur für + und ·.
  • Neutral: 0 bzw. 1. Invers: Gegenzahl bzw. Kehrwert. Durch 0 darf man nicht dividieren.
(8·9 + 7)·11 − 6·(5 + 72:6) = (72 + 7)·11 − 6·(5 + 12) = 79·11 − 6·17 = 869 − 102 = 767

2 · Potenzregeln

xa·xb = xa+b
xa : xb = xa−b
(xa)b = xa·b
(a·b)n = anbn
a0 = 1, a1 = a
x−n = 1/xn
a1/n = n√a
(2−3·424−4·22)−2 = (2−5·46)−2 = 210·4−12 = 210·2−24 = 2−14
