Spickzettel Mathe – 1. Schularbeit

Rechnen mit Zahlen · Potenzen · Gleitkomma · Einheiten (Skript Kapitel 1.1–1.4)

1.1 Reihenfolge

  • 3. Stufe Potenz, Wurzel → 2. Stufe · : → 1. Stufe + − . Gleiche Stufe: von links nach rechts.
  • Innerste Klammer zuerst. ( ) [ ] { } bedeuten dasselbe.
  • Potenz kommt vor dem Minus: −2² = −4 · (−2)² = 4 · (−2)³ = −8 · −(−3)² = −9
  • Negative Basis: gerader Exponent → +, ungerader → −.
  • Pro Zeile nur einen Schritt, jede Zeile ganz abschreiben.

1.2 Potenzregeln

xa · xb = xa+b
xa : xb = xa−b
(xa)b = xa·b
(a·b)n = an·bn · (x/y)n = xn/yn
a0 = 1 · a1 = a
x−n = (1/x)n = 1/xn · x−1 = 1/x
a1/n = n√a
(1/3)−2 = 32 = 9
  • Nur bei gleicher Basis! Mehrere Basen: erst sortieren.
  • Nicht kommutativ: 2³ ≠ 3². Nicht assoziativ: (2²)³ = 64, 2(2³) = 256.
  • Negativer Exponent macht das Ergebnis nicht negativ: 5−2 = 0,04.

1.2 Zehnerpotenzen

  • 10n = 1 mit n Nullen · 10−n = 1 an der n-ten Nachkommastelle (0,001 = 10−3).
  • Rezept: 1. alles als 10er-Potenz, 2. Potenzregeln. 1/0,000 001 = 106.
  • Minus minus: 1017 : 10−13 = 1017−(−13) = 1030.

1.3 Gleitkomma

normiert: ± m · 10e mit 1 ≤ m < 10
  • Komma n Stellen nach links → 10+n; nach rechts → 10−n. 0,000 002 14 = 2,14·10−6.
  • TR: SCI = normiert, ENG = Exponent in 3er-Schritten. 3,2E7 = 3,2·107. Eingabe: Taste ×10x / EE / EXP.
  • Mal: Mantissen mal, Exponenten plus, dann normieren.
  • Durch: ganze Mantissen hinschreiben, kürzen, dann normieren.
  • Hoch: (2·103)−3 = 2−3·10−9 = 0,125·10−9 = 1,25·10−10.
