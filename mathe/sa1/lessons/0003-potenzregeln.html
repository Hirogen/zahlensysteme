Potenzregeln: Exponenten addieren, subtrahieren, multiplizieren

Alle Potenzregeln folgen aus einem einzigen Gedanken: Eine Potenz ist eine abgekürzte Multiplikation. Wer das im Kopf hat, muss die Regeln nicht auswendig lernen – man kann sie jederzeit nachzählen.

Aufwärmen aus Lektion 2: Wie heißen die drei Teile von 34 = 81?

3 = Basis, 4 = Exponent, 81 = Potenz. Falls nicht: Lektion 2.

Was eine Potenz ist

34 = 3 · 3 · 3 · 3 = 81   4-mal der Faktor 3
a1 = aeinmal der Faktor a
a0 = 1x · a0: x wird gar nicht mit a multipliziert → bleibt x. Man nimmt auch 00 = 1.

Die Regeln – nachgezählt

Multiplizieren bei gleicher Basis

x2 · x4 = (x·x) · (x·x·x·x)
= x·x·x·x·x·x = x6 = x2+42 Stück + 4 Stück = 6 Stück

Dividieren bei gleicher Basis

x6x4 = x·x·x·x·x·xx·x·x·x
= x·x = x2 = x6−44 Stück kürzen sich weg

Potenz potenzieren

(x2)3 = x2 · x2 · x2
= x2+2+2 = x6 = x2·33-mal 2 Stück
xa · xb = xa+bMultiplizieren → Exponenten addieren (selbe Basis!)
xaxb = xa−bDividieren → Exponenten subtrahieren (selbe Basis ≠ 0!)
(xa)b = xa·bPotenz potenzieren → Exponenten multiplizieren
(a·b)n = an·bn
(xy)n = xnynJeder Faktor wird potenziert

Mehrere Basen: sortieren, dann zusammenfassen

x8·y70·a15x6·a12·y60 = a15a12 · x8x6 · y70y60 = a3·x2·y10Beispiel aus dem Skript

Potenzen sind weder kommutativ noch assoziativ: 23 = 8, aber 32 = 9. Und (22)3 = 26 = 64, aber 2(23) = 28 = 256. Ohne Klammer bedeutet 232 immer 2(32).

x2 · x4 ist nicht x8. Multiplizieren → addieren. Nur bei (x2)4 wird multipliziert.

Jetzt du

So tippst du Potenzen: x^5 für x5, x^-2 für x−2, mehrere Basen mit · oder einfach hintereinander: a^3x^2y^10. Unter dem Feld siehst du, wie das Programm deine Eingabe liest. (Negative Exponenten kommen in Lektion 4 genauer – hier darfst du sie einfach als Ergebnis hinschreiben.)
