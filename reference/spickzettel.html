Spickzettel Zahlensysteme

Basis b · Ziffern 0 bis b−1 · jede Stelle ist b-mal so viel wert wie die rechts daneben.

Welche Methode?

von → nachMethode
beliebig → dezimalStellenwert: Ziffer × bStelle, alles addieren. Stelle rechts = 0.
dezimal → beliebigDivision mit Rest durch b, bis Ergebnis 0. Reste von unten nach oben.
binär → hex / oktalVon rechts 4er- / 3er-Bündel, links mit 0 auffüllen.
hex / oktal → binärJede Ziffer → volle 4 / 3 Bit.
hex ↔ oktalÜber binär: auspacken, neu bündeln.
fremd → fremdÜber dezimal: erst hinein, dann hinaus.

Beispiele

  • 2A316 = 2·256 + 10·16 + 3 = 675
  • 2435 = 2·25 + 4·5 + 3 = 73
  • (1)(23)(7)50 = 1·2500 + 23·50 + 7 = 3657
  • 675 : 16 = 42 R 3 · 42 : 16 = 2 R 10=A · 2 : 16 = 0 R 2 → 2A316
  • 1101011 → 0110 1011 → 6B16 · 001 101 011 → 1538

Rechnen in Basis b

  • Plus: Spalte im Kopf dezimal addieren. Summe ≥ b → Summe − b schreiben, Übertrag 1.
  • Minus: oben zu klein → oben + b rechnen, Übertrag 1 zur unteren Ziffer der nächsten Spalte.
  • Probe: Minus mit Plus prüfen, oder beides dezimal nachrechnen.

Stellen zählen

  • Größte n-stellige Zahl: bⁿ − 1 (FF₁₆ = 255) · Anzahl: bⁿ · Bit für N: kleinstes k mit 2k > N

0 bis 15

Bündel ausrechnen mit 8-4-2-1. A=10 B=11 C=12 D=13 E=14 F=15

Komplementärzahl & Ersatzaddition

  • Dezimal: jede Ziffer → 9 − z, dann +1 rechts (2518 → 7482; 800 → 200)
  • Binär: 0 ↔ 1 tauschen, dann +1 rechts (110 → 001 → 010)
  • Stellenanzahl entscheidet: 97 → 03, aber 097 → 903
  • A − B: auf gleich viele Stellen (auch nach dem Komma!), A + Komplement(B), erste Stelle streichen

Binär multiplizieren

  • 1·1 = 1, sonst 0. Pro Ziffer des 2. Faktors eine Zeile: 1 → abschreiben, 0 → Nullen, jede Zeile 1 nach rechts
  • 1011 · 101 = 110111 (11 · 5 = 55) – Überprüfung im Dezimalsystem
  • MSB = linke, höchstwertige Stelle · LSB = rechte, Stellenwert 1

Fallen

  • Ziffer ≥ Basis gibt's nicht: 12898 ist ungültig.
  • Reste von unten nach oben lesen.
  • Bündeln immer von rechts.
  • Hex-Übertrag erst bei 16, Oktal bei 8 – nicht bei 10!
  • Basis als Index dazuschreiben.
