2 · Teilweise Wurzelziehen · unter die Wurzel

√72 = √36 · 2 = √36 · √2 = 6√2
  • Größte Quadratzahl als Faktor suchen (4, 9, 16, 25, 36, 49, 64, 81, 100 …). Fertig, wenn unten keine Quadratzahl mehr steckt.
  • Unter die Wurzel bringen (umgekehrt): Faktor quadriert hinein: 3√5 = √9 · 5 = √45.
  • Vergleichen: beide unter die Wurzel: 2√6 = √24 < √27 = 3√3.
  • Zusammenfassen nur gleiche Wurzeln (wie 2x + 5x): 2√3 + 5√3 = 7√3. Vorher teilweise ziehen: √12 + √27 = 2√3 + 3√3 = 5√3. √2 + √3 bleibt so!
  • Mit Klammer: √2(√8 + 3) = √16 + 3√2 = 4 + 3√2.

3 · Zahlenmengen

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ   ·   irrational = ℝ\ℚ
ℕ natürlich{0, 1, 2, 3, …} – in Österreich mit 0
ℤ ganz{…, −2, −1, 0, 1, 2, …}
ℚ rationalalle Brüche p/q (q ≠ 0): abbrechende und periodische Dezimalzahlen (0,3 = 1/3)
ℝ\ℚ irrationalunendlich, nicht periodisch: √2, √10, π, 2√3 (manche Bücher: 𝕀)
ℝ reellrational + irrational, füllt die Zahlengerade lückenlos
  • Immer ausführbar: + und · in ℕ · − in ℤ · : (nicht durch 0) in ℚ · √ (aus Zahlen ≥ 0) in ℝ.
  • ℚ und ℝ sind dicht (zwischen zwei Zahlen liegt immer noch eine), ℕ und ℤ nicht. ℕ hat eine kleinste Zahl (0), ℤ nicht.
  • Erst vereinfachen: √16 = 4 ∈ ℕ · −√9 = −3 ∈ ℤ · 12/4 = 3 ∈ ℕ · √3·√3 = 3. 1,4142 ist abbrechend → ℚ (nur Näherung von √2).
  • Periode → Bruch: 0,7 = 7/9 · 0,12 = 12/99 = 4/33.

7 · Rechnen mit Termen

  • +/−: nur gleichartige Glieder (gleiche Variablen, gleiche Exponenten). Minus vor der Klammer → alle Vorzeichen drehen: −(2x − 3) = −2x + 3.
  • Monom · Klammer: −3a(2a − 5) = −6a² + 15a. Klammer · Klammer: jedes Glied mit jedem: (2x − 3)(x + 4) = 2x² + 5x − 12.
  • : Monom: jedes Glied einzeln: (12x³ − 8x²) : 4x = 3x² − 2x.
  • Herausheben: größter Teiler + kleinste Potenz: 6x² − 9x = 3x(2x − 3). Probe: ausmultiplizieren.
  • Kürzen nur Faktoren, nie aus Summen: (x² − 9)/(x + 3) = (x+3)(x−3)/(x+3) = x − 3.

8 · Binomische Formeln

1. (a + b)² = a² + 2ab + b²
2. (a − b)² = a² − 2ab + b²
3. (a + b)(a − b) = a² − b²
  • (3x − 2y)² = 9x² − 12xy + 4y² · Mittelglied nicht vergessen! (x + 5)² ≠ x² + 25.
  • Rückwärts: außen Quadrate suchen, Mittelglied prüfen: 9x² − 12x + 4 = (3x − 2)² · 4x² − 25 = (2x + 5)(2x − 5).
  • Kopfrechnen: 41² = (40 + 1)² = 1681 · 29 · 31 = 30² − 1 = 899.
  • Bei „− ( … )²“ erst ausrechnen, in Klammer lassen, dann Vorzeichen drehen.
